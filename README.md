# Комнаты

Пилот: анонимные голосовые комнаты для знакомства студентов. Одно приложение для iOS, Android и браузера.

Документация — в папке [docs/](docs/). Правила проекта — в [CLAUDE.md](CLAUDE.md).

## Что где лежит

| Папка | Что это |
|---|---|
| `apps/mobile` | приложение (Expo + React Native), работает и в браузере |
| `apps/server` | сервер (Node.js + Fastify) |
| `packages/shared` | общие типы и проверки данных для приложения и сервера |
| `docs` | архитектура, модель данных, API, правила модерации, решения, открытые вопросы |

## Как запустить

Нужны Node.js 22+ и pnpm.

```bash
pnpm install
```

Сервер (адрес http://localhost:3000):

```bash
pnpm dev:server
```

Приложение в браузере (адрес http://localhost:8081):

```bash
pnpm dev:web
```

Приложение на телефоне (откроется QR-код для приложения Expo Go):

```bash
pnpm dev:mobile
```

Чтобы телефон видел сервер, запускайте приложение с адресом компьютера в домашней сети, например `EXPO_PUBLIC_API_URL=http://192.168.1.10:3000 pnpm dev:mobile`.

## Как проверить

```bash
pnpm check
```

Команда проверяет типы и запускает все автотесты. Та же проверка автоматически идёт на GitHub при каждой отправке кода.
