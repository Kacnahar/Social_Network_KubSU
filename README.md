# Студенческая соцсеть

Соцсеть для студентов: профиль, посты, истории, лента — и анонимные голосовые комнаты как один из разделов. Сейчас сделаны вход и раздел комнат; остальное — по частям, см. [docs/ROADMAP.md](docs/ROADMAP.md). Одно приложение для iOS, Android и браузера.

Документация — в папке [docs/](docs/). Правила проекта — в [CLAUDE.md](CLAUDE.md).

## Что где лежит

| Папка | Что это |
|---|---|
| `apps/mobile` | приложение (Expo + React Native), работает и в браузере |
| `apps/server` | сервер (Node.js + Fastify) |
| `packages/shared` | общие типы и проверки данных для приложения и сервера |
| `docs` | план работ, архитектура, модель данных, API, правила модерации, решения, открытые вопросы |

Внутри каждой из трёх папок с кодом — одно и то же деление: **ядро** соцсети (вход, аккаунт, уведомления) и **модули** (сейчас один — голосовые комнаты).

## Как запустить

Нужны Node.js 22+ и pnpm.

```bash
pnpm install
```

Сервер (адрес http://localhost:3000):

```bash
pnpm dev:server
```

Сервер звука — нужен, чтобы входить в комнаты (ставится один раз: `brew install livekit`):

```bash
livekit-server --dev
```

Приложение в браузере (адрес http://localhost:8081):

```bash
pnpm dev:web
```

Приложение на телефоне (откроется QR-код для приложения Expo Go):

```bash
pnpm dev:mobile
```

Чтобы телефон видел сервер, запускайте приложение с адресом компьютера в домашней сети, например `EXPO_PUBLIC_API_URL=http://192.168.1.10:3000 pnpm dev:mobile`.

## Как войти при разработке

Коды приглашения: `TEST-2026` — студент, `TEACHER-2026` — преподаватель, `GUEST-2026` — гость. Почта — любая (например, `me@example.com`). Чтобы увидеть админку, зарегистрируйтесь с почтой `admin@example.com`. Письма пока не отправляются: код для входа показывается прямо на экране. База данных создаётся сама в папке `apps/server/.data`.

## Как проверить

```bash
pnpm check
```

Команда проверяет типы и запускает все автотесты. Та же проверка автоматически идёт на GitHub при каждой отправке кода.
