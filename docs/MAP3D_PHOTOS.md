# 3D-карта: какие фото нужны

Список снимков, которые помогут сделать модель точной. Подойдут обычные фото с телефона, днём, по возможности без людей в кадре. Присылать можно частями — в чат с Claude Code или в папку `photos/` рядом с проектом.

Отмечайте сделанное галочкой: `[x]`.

## Как снимать

- Телефон держать горизонтально, без сильного наклона вверх.
- Здание целиком — издалека; детали — с 2–3 метров.
- Если деталь повторяется (окна, плитка, фонари), достаточно одного чёткого снимка.
- Номера кабинетов — чтобы цифры читались.

## 1. Главный вход и центральный блок (самое важное)

- [ ] Центральный блок целиком, прямо спереди, от ворот.
- [ ] Центральный блок под углом слева и под углом справа — видно, как он стыкуется с крыльями.
- [ ] Крыльцо: ступени, сколько их, есть ли пандус и перила.
- [ ] Входные двери крупно: сколько створок, цвет рам, ручки.
- [ ] Козырёк над входом снизу и сбоку.
- [ ] Высокие окна между белыми рёбрами — один пролёт крупно.
- [ ] Верхний пояс с надписью — целиком (нужно понять размер и место; сам текст на карте появится только после вашего решения).
- [ ] Таблички и вывески у входа.

## 2. Крылья главного корпуса

- [ ] Фасад западного крыла вдоль Ставропольской — участок на 5–6 окон.
- [ ] Фасад восточного крыла — так же.
- [ ] Одно окно крыла крупно: рама, подоконник, что между окнами по вертикали и по горизонтали.
- [ ] Торец западного крыла с мозаикой — целиком (саму мозаику я не воспроизвожу, нужны размер и место панно).
- [ ] Угол здания сверху: карниз, край крыши, водосточная труба.
- [ ] Цоколь (низ стены у земли) — цвет и высота.
- [ ] Все остальные входы в корпус: каждая дверь со ступенями и козырьком, плюс общий снимок, чтобы понять, где она.
- [ ] Кондиционеры и решётки на фасаде, если есть, — один общий снимок стены.

## 3. Внутренние дворы

- [ ] Каждый внутренний двор между крыльями — по одному общему снимку из угла.
- [ ] Что во дворах: дорожки, скамейки, клумбы, парковка.
- [ ] Отдельное небольшое здание во дворе восточной части — что это и как выглядит.

## 4. Площадь и территория

- [ ] Плитка на площади перед входом крупно, сверху вниз (рисунок и цвета).
- [ ] Обычная плитка дорожек и бордюр крупно.
- [ ] Асфальтовые проезды — один снимок.
- [ ] Газоны перед входом: где живая изгородь, где круглые кусты, где ели.
- [ ] Ограда вдоль Ставропольской и ворота — общий снимок и участок крупно.
- [ ] Остальные ворота и калитки на территории — каждая.
- [ ] Фонарь, скамейка, урна — по одному снимку каждого вида.
- [ ] Парковка: где она и какая разметка.
- [ ] Стенды, флагштоки, памятники, если есть.
- [ ] «Куб мудрости» перед Центром Интернет: общий снимок издалека (чтобы было видно, где он стоит относительно входа и проезда) и клумба вокруг него с двух сторон.
- [ ] Церковь на территории — фасад со входом и вид сбоку.
- [ ] Белая беседка во внутреннем дворе.

## 5. Футбольное поле (для следующего блока)

- [ ] Поле целиком с угла.
- [ ] Ворота, сетка, разметка крупно.
- [ ] Трибуны: с какой стороны, сколько рядов.
- [ ] Беговая дорожка вокруг поля, если есть: цвет, число полос.
- [ ] Ограждение поля и вход на стадион.
- [ ] Путь от главного корпуса до поля — 2–3 снимка по дороге.

## 6. Остальные здания на территории

- [ ] Столовая — фасад со входом.
- [ ] Каждое общежитие — один снимок фасада (цвет стен, этажность).
- [ ] Постройки в северной части территории — общий снимок.

## 7. Внутри корпуса (понадобится позже)

Главное, чего нет ни в одном источнике, — **номера кабинетов на схемах**.

- [ ] Планы эвакуации на стенах каждого этажа — каждый план целиком, чтобы читались номера. Это самые ценные снимки.
- [ ] Холл первого этажа из двух углов.
- [ ] Один типичный коридор: пол, стены, потолок, светильники, двери.
- [ ] Дверь кабинета с номером и табличкой крупно.
- [ ] Лестница: ступени, перила, площадка.
- [ ] Один типичный кабинет: парты, доска, окна.

## Что уже известно и откуда

- Контуры зданий, ограда, поле, дорожки, газоны — OpenStreetMap.
- Форма и цвета центрального блока и крыльев, плитка площади, ели и кусты у входа, фонари, ограда — уличные панорамы официального виртуального тура (только как образец; картинки тура в приложение не копируются).
- Высота этажей — типовая: 3,6 м у учебного корпуса, 3,0 м у остальных зданий. Точных высот в источниках нет.
