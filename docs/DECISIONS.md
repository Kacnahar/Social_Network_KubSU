## Техника (2026-11-22)

**T1. Одно приложение на Expo (React Native) + TypeScript для iOS, Android и веба.**
Отдельные приложения под каждую платформу отвергнуты: примерно в 2,7 раза дороже.

**T2. Сервер на Node.js + TypeScript, фреймворк Fastify.**
Один язык с приложением, общие типы. Отвергнуто: NestJS (тяжелее, чем нужно пилоту), Python/Go (второй язык).

**T3. Монорепозиторий на pnpm workspaces: `apps/mobile`, `apps/server`, `apps/admin`, `packages/shared`.**
Один репозиторий проще для команды из двух человек; общие типы без публикации пакетов.

**T4. PostgreSQL + Drizzle ORM.**
Надёжная база, есть у любого российского хостинга. Drizzle — лёгкий, типы из схемы.

**T5. Redis — для состояния «прямо сейчас».**
Кто в комнате, идущие голосования, ограничения частоты. В базе это было бы медленно и шумно.

**T6. Голос — LiveKit на своём сервере, только звук, без компонента записи.**
Открытый код, готовые модули для React Native и веба, сервер может сам отключить микрофон и удалить участника. Отвергнуто: LiveKit Cloud и Agora (данные за рубежом), свой WebRTC с нуля (месяцы работы).

**T7. События в реальном времени — свой WebSocket на сервере.**
Голосования и чат должен контролировать наш сервер. LiveKit используется только для звука. Отвергнуто: передавать события через канал данных LiveKit (чат не привязан к комнате).

**T8. Аккаунт и персона — раздельные сущности, мост в одной таблице, доступ через один модуль `identity`.**
Так требование «ник нельзя связать с аккаунтом» выполняется устройством кода, а не аккуратностью. Проверяется автотестом на все ответы API.

**T9. Сессии — непрозрачные токены, хранятся на сервере (не JWT с данными внутри).**
В токене нечего подсмотреть; сессию можно мгновенно отозвать при бане.

**T10. Невзаимные отметки не отдаются ни в одном запросе (включая админку) и удаляются после 24-часового окна.**
Буквальное выполнение «не видит никто».

**T11. Сбор ошибок — GlitchTip на своём сервере, через Sentry SDK.**
Критерий «≥99% сессий без падений (Sentry)» сохраняется, но данные не уходят за рубеж. Облачный Sentry отвергнут из-за P12. Требует подтверждения — см. OPEN_QUESTIONS.

**T12. Метрики — своя таблица событий, без сторонней аналитики.**
Данные в РФ, бесплатно, считаем ровно пять метрик пилота.

**T13. Push — Expo Push для телефонов и Web Push для браузера; в тексте push нет личных данных.**
Проще всего. Оговорка: уведомления проходят через зарубежные серверы (Expo, Apple, Google) — см. OPEN_QUESTIONS.

**T14. Админка — отдельное веб-приложение, вход с двухфакторной защитой, неизменяемый журнал.**
«Анонимно, но не для модерации» — с контролем за самими админами.

**T15. Развёртывание — Docker Compose на одном-двух серверах.**
Для пилота на сотни человек Kubernetes избыточен.

**T16. Инструменты разработки: uv + Python 3.12 только для Graphify; сам проект — Node.js.**
