# Модель данных

Какие таблицы есть и будут в базе (PostgreSQL). Точное описание созданных таблиц — в `apps/server/src/db/schema/`. Пометки: ✅ создана, ⏳ запланирована.

Таблицы делятся на три группы:

- **Ядро соцсети** (`schema/core.ts`) — аккаунт, вход, приглашения, уведомления, профиль.
- **Модуль «Голосовые комнаты»** (`schema/rooms.ts`) — имена таблиц начинаются с `room`. Знают только анонимную персону.
- **Мост** (`schema/bridge.ts`) — одна таблица, связывающая аккаунт с персоной комнат.

Будущие модули (лента, друзья, сообщения, группы) получат свои файлы таблиц и свой префикс в именах.

## Три личности

```
   accounts ─────────── profiles            (ядро: закрытый аккаунт и открытый профиль)
      │
      │  persona_links  ← единственный мост, читает только core/identity
      │
   room_personas                             (модуль комнат: анонимный ник)
```

Профиль и персона напрямую не связаны нигде. Чтобы узнать, чей ник, нужен «мост» — а он доступен только одному модулю сервера и админке с журналом.

## Ядро соцсети

### accounts — аккаунт ✅
Закрытая часть: не видна никому, кроме сервера и админов.

| Поле | Что это |
|---|---|
| id | внутренний идентификатор, наружу не выходит |
| email_encrypted | почта в зашифрованном виде |
| email_hash | отпечаток почты для поиска при входе, уникальный |
| invite_code_id | каким кодом приглашения воспользовался |
| status | active / banned |
| banned_until | до какого времени бан |
| created_at | когда создан |

### profiles — открытый профиль соцсети ⏳
Открытая личность человека в соцсети. Один профиль на аккаунт.

| Поле | Что это |
|---|---|
| id | публичный идентификатор (`profileId`) — его видят другие пользователи |
| account_id | чей профиль; уникальный, наружу не выходит |
| display_name | имя, как человек себя назвал |
| faculty, course | факультет и курс |
| about | о себе |
| avatar | фото — под вопросом (F3) |
| created_at, updated_at | когда создан и изменён |

Состав полей и кто что видит — не решено (вопросы F2–F3). Таблица появится вместе с первой функцией соцсети — «Профиль».

### invite_codes — коды приглашений ✅
id, code, label (пометка для нас), max_uses и used_count, expires_at, created_at.

### email_login_codes — одноразовые коды входа ✅
email_hash, code_hash, invite_code_id (если это регистрация), deliverable (отправлялось ли письмо), attempts (не больше 5), expires_at (10 минут), created_at. Одна запись на почту.

### sessions — сессии входа ✅
id, token_hash, account_id, expires_at (90 дней), created_at. Токен — случайная строка, в базе только её отпечаток.

### push_subscriptions — адреса для уведомлений ✅
account_id, kind (пока только `webpush` — браузер), endpoint, p256dh и auth (ключи шифрования), created_at. Наружу не отдаётся. Уведомления — общая служба ядра: ею пользуются комнаты, позже — сообщения и лента.

### account_sanctions — санкции ⏳
account_id, type, источник (голосование в комнате / автоматика / админ), срок. Действует ли бан из комнат на всю соцсеть — вопрос F6.

### admins, admin_audit_log — админы и журнал ⏳
В журнал пишется каждый просмотр связи «ник комнат ↔ аккаунт/профиль», каждый бан и разбан. Записи не редактируются.

### events — события для метрик ⏳
Без идентификатора аккаунта и без почты.

## Мост

### persona_links ✅
account_id, persona_id. Одна персона на аккаунт. **Читает только `core/identity`** — это проверяет автотест.

## Модуль «Голосовые комнаты»

### room_personas — анонимная персона ✅
То, что видят собеседники в комнате.

| Поле | Что это |
|---|---|
| id | публичный случайный идентификатор (`personaId`) |
| nickname | ник комнат; пустой, пока человек его не выбрал |
| nickname_key | ник в нижнем регистре с «ё»→«е» — для проверки уникальности |
| nickname_changed_at | когда менялся (смена не чаще раза в 30 дней) |
| created_at | когда создана |

### room_slots — расписание ✅
id, title, starts_at (уникальное), duration_minutes, status (scheduled / cancelled), created_at. «Идёт» и «закончилась» вычисляются по времени.

### room_slot_reminders — отправленные напоминания ✅
slot_id, minutes_before (60 или 5), sent_at. Чтобы каждое напоминание ушло ровно один раз.

### rooms — комнаты ✅
id, slot_id, index (1, 2, …), voice_room_name (случайное имя на сервере звука), opened_at, closed_at.

### room_participations — кто был в комнате ✅
room_id, persona_id, joined_at, left_at. Нужна для списка «с кем я был в комнате», метрик и правил голосования. Поля «брал ли слово» добавятся вместе с метриками.

### room_votes, room_vote_ballots — голосования ⏳
Тип (выгнать / выключить микрофон), против кого, кто начал, окно, число участников, итог; отдельные голоса видны только в журнале админов.

### room_personal_mutes — «заглушить для себя» ⏳
persona_id, muted_persona_id.

### room_reports — «Сообщить админам» ⏳
Кто, на кого, из какой комнаты, текст, статус.

### room_marks — тайные отметки «хочу пообщаться ещё» ⏳
from_persona_id, to_persona_id, room_id, created_at. Не отдаются ни в одном запросе и не показываются в админке; невзаимные удаляются через 24 часа.

### room_matches, room_match_reveals — взаимные мэтчи и открытые ступени ⏳
«Знакомые по комнатам». Каждый открывает свои ступени отдельно.

### room_reveal_cards — что человек показывает на ступенях ⏳
Раньше планировалась отдельная анкета (факультет, курс, интересы; затем имя и ссылка на VK/Telegram). Теперь, когда есть профиль соцсети, возможно, вторая ступень должна открывать сам профиль. Не решено — вопрос F5.

### room_chat_messages — чат после второй ступени ⏳
Удаляются через 90 дней. Под вопросом: если в соцсети будет модуль «Сообщения», отдельный чат комнат может быть не нужен (вопрос F7).

## Будущие модули (таблиц ещё нет)

| Модуль | Что будет хранить | К чему привязано |
|---|---|---|
| Друзья | заявки и связи между профилями | профиль |
| Лента и посты | посты, фото, отметки «нравится», комментарии | профиль |
| Сообщения | переписка между профилями | профиль |
| Группы | группы, участники, записи групп | профиль |
| Новости и объявления | записи от админов и в профилях | профиль / админ |

Все они работают с **профилем**. С персоной комнат работает только модуль комнат.

## Сроки хранения

| Данные | Срок |
|---|---|
| Невзаимные отметки | до конца 24-часового окна |
| Одноразовые коды входа | 10 минут |
| Сообщения чата комнат | 90 дней |
| События метрик | до конца пилота + отчёт (уточнить) |
| Журнал админов | не удаляется на время пилота |
| Аккаунт, профиль, персона и всё связанное | до удаления по запросу пользователя |
