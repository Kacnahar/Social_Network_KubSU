## Часть 3. Лента и главный экран — готово

**Что теперь умеет приложение**
- Нижнее меню: Лента, Войс, Создать, Профиль. Студент видит все четыре вкладки, преподаватель — без «Войса», гость — только «Ленту» и «Профиль».
- Лента: посты всех пользователей, новые сверху, подгружаются при прокрутке.
- Под заголовком ленты закреплена строка «Анонимный войс» с маленьким «живым» шаром: при прокрутке она остаётся вверху. Нажатие открывает вкладку «Войс» — там большой шар, кнопка «Войти», расписание и напоминания.
- Вкладка «Создать» — новый пост; после публикации он появляется вверху ленты.
- Вкладка «Профиль» — свой профиль, свои посты, выход и удаление аккаунта.

**Как проверено**
- В браузере студентом: лента подгрузила вторую порцию (25 постов), строка войса осталась закреплённой; лента → строка войса → «Войти» → комната (в первый раз — экран ника); пост из вкладки «Создать» появился вверху ленты.
- Преподавателем: три вкладки, строки войса нет, адрес `/voice` возвращает на ленту, запросов к комнатам нет.
- Гостем: две вкладки, кнопок лайка нет (только счётчики), адрес `/create` возвращает на ленту.

**Что нашёл и исправил**
- В строке войса кнопка-шар была вложена в кнопку-строку, браузер на это ругался. Теперь шар там — просто украшение.

**Не проверено**
- Как нижнее меню и закреплённая строка ведут себя на iPhone и Android.
- Жест «потянуть, чтобы обновить» (в браузере его нет).
